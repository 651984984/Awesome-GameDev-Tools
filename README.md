# Awesome-GameDev-Tools

Game Development Tools Research

ren.py, https://www.renpy.org, Visual novel engine for python, provides framework for devs to add images dialouge and branching storylines
pygame, https://github.com/pygame/pygame, open source python library for 2d game development
python arcade, https://github.com/pythonarcade/arcade, 2d game dev library designed to to be simple for begineers 
godot, https://godotengine.org, general prupose 2d and 3d game engine
fantasy name gen, https://www.fantasynamegenerators.com, make names for anyone really helpoful cause names are hard
blender, https://www.blender.org, 3d modeling software
maya, https://www.autodesk.com/products/maya/overview,  3d animation and vfx tool
asperite, https://github.com/aseprite/aseprite, sprite animation and pixal art software
reaper Wwise, https://github.com/mhasselbalch/ReaperToWwise, game audio tool
github, https://github.com, dev platform for storing, tracking and sharing applications
